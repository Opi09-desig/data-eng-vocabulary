# Data Engineering Vocabulary Flashcards 🚀

An interactive web app to learn technical English vocabulary for Data Engineering at B2 level.
Built with pure HTML, CSS, and JavaScript — no frameworks, no installations needed.

---

## ✨ Features

- **3D flip cards** — click a card to reveal the meaning and an example sentence
- **Quiz mode** — type the meaning before seeing the answer to practice active recall
- **Streak counter 🔥** — tracks how many correct answers you get in a row
- **Mark as mastered** — tag words you already know to track your progress
- **Progress bar** — see how far you are in the deck
- **Keyboard shortcuts** — navigate and answer without touching the mouse
- **Persistent progress** — your position and mastered words are saved in the browser

---

## 🗂️ Project Structure

```
vocab-flashcards/

├── style.css        # Dark theme styles and card animations
├── app.js           # App logic: navigation, quiz, mastered words
└── vocabulary.js    # List of 32 vocabulary words with phonetics and examples
```

---

## ▶️ How to Run

No server or installation required.

1. Download or clone this repository
2. Open `index.html` in any modern browser
3. Start studying!

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `→` | Next card |
| `←` | Previous card |
| `Space` | Flip card |
| `Enter` | Check answer (quiz mode) |
| `M` | Mark / unmark as mastered |

## 🛠️ Technologies

- **HTML5** — structure and semantic markup
- **CSS3** — dark theme, 3D flip animation, responsive layout
- **Vanilla JavaScript** — DOM manipulation, quiz logic, state management
- **LocalStorage API** — saves progress between sessions
